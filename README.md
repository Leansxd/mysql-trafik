# 4 Yönlü Akıllı Trafik Lambası Simülasyonu

SQL (DDL, DML, INNER JOIN) ve PHP ile geliştirilmiş, gerçek zamanlı 4 yönlü sıralı trafik lambası kontrol sistemi.

## Hızlı Başlangıç

Projeyi herhangi bir bilgisayarda çalıştırmak için:

1. Proje klasöründe terminali açın:
```bash
php -S localhost:8000
```

2. Tarayıcıda adresi açın:
```
http://localhost:8000
```

Herhangi bir veritabanı kurulumuna gerek yoktur; `database.sql` dosyası PHP tarafından otomatik işlenir.
